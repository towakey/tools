# Markdown Viewer

外部通信なし・単一HTMLファイルで動くMarkdownビューワーです。

## 使い方

1. `index.html` の `MD_FILE` (script先頭付近) に表示したいmdファイルのパスを書く
2. IIS などのWebサーバーに `index.html` と md ファイルを置いて開く

`file://` で直接開いた場合はブラウザ制限のため自動読み込みできません。
その場合は右上の「MDファイルを開く」ボタンからファイルを選択してください。

文字コードは UTF-8 と Shift-JIS を自動判別します。

## IIS で 404 になる場合

IIS は `.md` のMIMEタイプを既定で持たないため、mdファイルの取得が 404 になります。
どちらかで対処してください。

- 同梱の `web.config` を index.html と同じ場所に置く（既存の web.config がある場合は `<mimeMap>` の行をマージ）
- または md ファイルを `.txt` にリネームして `MD_FILE` をその名前にする（サーバー設定不要。`.txt` は既定で配信される）

## 対応記法

- 見出し (`#` 〜 `######`)、**太字**、*斜体*、~~打消し~~、`インラインコード`
- コードブロック、引用、リスト(2段ネストまで)、チェックボックス `- [ ]`
- テーブル、リンク、画像、水平線
- md内のHTMLタグはエスケープされてそのまま表示されます

| 項目 | 値 |
|------|---:|
| 必要なファイル | index.html のみ |
| 外部通信 | 不要 |
