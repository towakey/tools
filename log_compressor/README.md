# log_compressor

対象ディレクトリ内のログファイルを検索・一括圧縮するWindows向けTUIツール。
`compress_tui.bat` をダブルクリックで起動する。追加パッケージは不要
（7-Zip または Windows 標準 tar.exe があればそれを使用、なければ Compress-Archive で作成）。

## 使い方

| キー | 動作 |
|---|---|
| ↑↓ / Tab | 項目移動 |
| 文字入力 / BackSpace / Delete | 項目の編集 |
| Enter | 次の項目へ／実行（対象ディレクトリではディレクトリ選択モード） |
| Esc | 終了 |

### ディレクトリ選択モード

対象ディレクトリにカーソルを合わせて Enter で起動。
現在のディレクトリ内のサブディレクトリを一覧表示する。

| キー | 動作 |
|---|---|
| ↑↓ | カーソル移動 |
| → | 選択中のディレクトリに入る |
| ← | 上の階層へ戻る |
| Esc | 表示中のディレクトリに決定してメニューへ戻る |

## 設定項目

bat ファイル冒頭の `set` 行で初期値を変更可能。

- `TARGET_DIR` : 対象ディレクトリ（既定は実行時のカレントディレクトリ）
- `INCLUDE_EXTS` : 圧縮対象の拡張子（空欄＝すべて）
- `EXCLUDE_EXTS` : 除外拡張子（既定 `zip bat`）
- `TARGET_PATTERN` : 検索文字列（第1引数でも指定可）

実行すると対象ファイル一覧を表示し、確認後に `logs_<検索文字列>.zip` を作成して元ファイルを削除する。
